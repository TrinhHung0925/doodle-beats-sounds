# Credits

## GeneralUser GS

All instrument sounds in this repository come from **GeneralUser GS v2.0.3** by **S. Christian Collins**.

- Website: https://www.schristiancollins.com/generaluser
- Source: https://github.com/mrbumpy409/GeneralUser-GS (commit `684543d5e5efaef08d02be50dcda8d552478fa60`, `GeneralUser-GS.sf2`, sha256 `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`)
- License: see [`LICENSE-GeneralUser-GS.txt`](LICENSE-GeneralUser-GS.txt) (GeneralUser GS License v2.0)

The original bank was split into one `.sf2` file per preset. Sample data, generators and modulators are copied unchanged; only the packaging (indices, sample offsets, INFO name) differs. Some display names were expanded (e.g. "Tine EP" → "Tine Electric Piano", "Celeste" → "Celesta", drum kits get a "Kit" suffix).

Thank you, Chris, for making GeneralUser GS free for everyone.
